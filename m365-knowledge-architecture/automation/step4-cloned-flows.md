# Step 4 — Cloned Flows for All Input Types

The classification brain (`step3-brain-prompt.json`) is identical across all flows.
Only the **trigger** and **content extraction step** change.

---

## Flow 2: `KM | Teams Transcript → Classify & Store | PROD`

### Trigger
**Microsoft Teams — When a call ends** (requires Teams admin consent for `CallRecords.Read.All`)

Or, more practically via **SharePoint trigger**:
**SharePoint — When a file is created** in the Teams recordings library:
```
Site: https://octaveint.sharepoint.com/sites/DaniandEthan
Library: /Recordings  (where Teams auto-saves meeting recordings)
```

### Content Extraction (replaces Step 2-3 of email flow)

**Step 2A — Get file metadata**
```
SharePoint — Get file metadata using path
Path: @{triggerOutputs()?['body/{Path}']}
```

**Step 2B — Get transcript text**

Option A — VTT file (auto-generated by Teams):
```
SharePoint — Get file content
Path: [same path with .vtt extension]
```
Parse VTT → strip timestamps → extract plain text (use a **Compose** with regex or a small Azure Function)

Option B — Use Graph API to get transcript directly:
```
HTTP GET https://graph.microsoft.com/v1.0/me/onlineMeetings/{meetingId}/transcripts/{transcriptId}/content
Headers: Authorization: Bearer @{body('Get_Graph_Token')?['access_token']}
         Accept: text/vtt
```

**Compose — Build content payload**
```json
{
  "source": "Teams",
  "meeting_title": "@{triggerOutputs()?['body/Name']}",
  "meeting_date": "@{triggerOutputs()?['body/TimeLastModified']}",
  "transcript_text": "@{first(2000, outputs('Get_Transcript_Text'))}",
  "attendees": "@{outputs('Get_Meeting_Metadata')?['attendees']}"
}
```

### Store (replaces Step 5-6 of email flow)
```
Library:    meeting-transcripts
File name:  @{formatDateTime(triggerOutputs()?['body/TimeLastModified'], 'yyyy-MM-dd')}_@{substring(body('Parse_JSON')?['objective'],0,3)}_TRANSCRIPT_@{replace(triggerOutputs()?['body/Name'],' ','_')}
```

Additional metadata fields:
- `MeetingDate`: `@{triggerOutputs()?['body/TimeLastModified']}`
- `ContentTypeLabel`: `Meeting Transcript` (hardcoded)

## Flow 3: `KM | OneDrive File → Classify & Store | PROD`

### Trigger
**OneDrive for Business — When a file is created**
```
Folder: /Shared Documents  (or a designated drop folder like /KM-Inbox)
```

### Content Extraction

**Step 2A — Detect file type**
```
Condition: @{triggerOutputs()?['body/contentType']} 
  contains 'spreadsheet'  → Excel path
  contains 'pdf'          → PDF path  
  contains 'wordprocessing'→ Word path
```

**Excel path — Extract cell content**
```
Excel Online (Business) — Get tables
Location: OneDrive for Business
Document Library: OneDrive
File: @{triggerOutputs()?['body/id']}
```
Then: **List rows present in table** → join all rows into a single string for LLM

**Word/PDF path:**
Use **AI Builder — Extract information from documents** (prebuilt model) to get text content,
OR pass file bytes to a lightweight Azure Function that returns extracted text.

**Compose — Build content payload**
```json
{
  "source": "Upload",
  "file_name": "@{triggerOutputs()?['body/name']}",
  "file_type": "@{triggerOutputs()?['body/contentType']}",
  "uploaded_by": "@{triggerOutputs()?['body/lastModifiedBy/user/email']}",
  "upload_date": "@{triggerOutputs()?['body/lastModifiedDateTime']}",
  "extracted_text": "@{outputs('Compose_-_Extracted_Text')}"
}
```

### Store
```
Site:    [routed by objective — same logic as email flow]
Library: ai-inbox (then promoted after confidence check)
```

## Flow 4: `KM | Excel Upload → Tag & Route | PROD`

This is a specialized variant of Flow 3 for Excel files that need richer extraction.

### Trigger
**SharePoint — When a file is created or modified**
```
Site:    https://octaveint.sharepoint.com/sites/DaniandEthan
Library: spreadsheets
```

### Content Extraction

**Step 2A — List all worksheets**
```
Excel Online (Business) — List tables
File: @{triggerOutputs()?['body/ServerRelativeUrl']}
```

**Step 2B — For each worksheet, get rows (first 50)**
```
Excel Online (Business) — List rows present in a table
Limit: 50 rows per sheet
```

**Step 2C — Extract named ranges and column headers**
Headers often contain the most classification-relevant signal:
```
Compose: join all column headers + first 5 rows of data
Output: "Columns: SKU, Product Name, List Price, Tier, Margin | Row1: SKU-001, Widget A, $99, Tier1, 42%..."
```

**Compose — Build content payload**
```json
{
  "source": "Upload",
  "file_name": "@{triggerOutputs()?['body/Name']}",
  "content_type_hint": "Spreadsheet",
  "worksheet_summary": "@{outputs('Compose_-_Headers_and_Rows')}",
  "uploaded_by": "@{triggerOutputs()?['body/Editor']}"
}
```

### Special routing for Excel
After classification:
- If `keywords` contains `pricebook` OR `price list` → also tag with `RetentionLabel = Financial-7yr`
- If `keywords` contains `SKU` → link to `SKU-Catalog` library via cross-reference metadata field
- If `confidence < 0.75` → require Owner review (not just any reviewer)

## Summary: What Changes Per Flow

| Flow                 | Trigger                    | Extraction step                      | Store library       |
|----------------------|----------------------------|--------------------------------------|---------------------|
| Email + Attachment   | Outlook: new email         | Email body + attachment binary       | `email-archives`    |
| Teams Transcript     | SP: new file in Recordings | VTT/Graph transcript text            | `meeting-transcripts`|
| OneDrive File        | OneDrive: new file         | AI Builder / Azure Function text     | `classified-documents`|
| Excel Upload         | SP: new Excel file         | Excel connector headers + sample rows| `spreadsheets`      |

**Brain prompt**: identical across all 4. Change only `{{content}}`.
